Windows + Chrome — 4 adım

Hiç kod yazmayacaksınız. Sadece çift tıklayacaksınız.

1

ZIP'i çıkar

GhostPilot_Paketi.zip → sağ tık → Tümünü ayıkla → hedef Belgeler.

C:\Users\KullanıcıAdınız\Belgeler\GhostPilot

ZIP'in içinden çalıştırmayın — mutlaka çıkarın.
2

Python kur (tek seferlik)

python.org/downloads → Download Python → kurulumda “Add python.exe to PATH” kutusunu işaretle → Install Now.

Bu kutu işaretlenmezse kur.bat çalışmaz. En sık yapılan hata.
3

kur.bat'a çift tıkla

Pencere açılır ve şunu yazar:

✓ Tüm dosyalar yerinde.
✓ Köprü çalışıyor: http://127.0.0.1:17380

Masaüstü kontrolü istemiyorsanız bu adımı atlayabilirsiniz.

4

Chrome'a yükle

  1. Adres çubuğu: chrome://extensions
  2. Sağ üst: Geliştirici modu → aç
  3. Sol üst: Paketlenmemiş öğe yükle
  4. Şu klasörü seç:

...\Belgeler\GhostPilot\extension-chromium

  1. 🧩 puzzle simgesi → GhostPilot yanındaki 📌 çiviyi tıkla
  2. 👻 simgesine tıkla → panel açılır
extension-chromium klasörünün kendisini seçin — ana klasörü değil.

Bağlan — 3 farklı yol

🔐 Otomatik (Gemini · OpenRouter)

Mor “Tarayıcıda giriş yap ve bağlan” düğmesine bas → hesabınla gir → izin ver → anahtar kendiliğinden kaydedilir.

OpenRouter kalıcı anahtar verir. Gemini ~1 saatlik jeton verir; süre bitince aynı düğmeye tekrar bas.

⌨️ Elle anahtar

Anahtarı kutuya yapıştır → 💾 Kaydet. Anahtar kalıcı olarak saklanır, bir daha girmen gerekmez.

Her sağlayıcı için ayrı ayrı saklanır. İstediğin an “Bağlı hesaplarım” listesinden geçiş yap.

🦙 Anahtarsız (Ollama)

Kartta Ollama'yı seç, uygulama açık olsun, Test Ete bas. Anahtar kutusu hiç görünmez.

3

Kayıtlı hesaplar

İkinci kartta bağladığın tüm hesaplar listelenir: sağlayıcı adı, maskeli anahtar (sk-pro…5678), model ve tarih.

  • Kullan → o sağlayıcıya anında geç
  • Yeşil AKTİF etiketi → şu an hangisi kullanılıyor
  • Süresi dolmuş jetonlar “süresi doldu” olarak işaretlenir
Kaç sağlayıcı eklerseniz ekleyin, her biri ayrı saklanır — biri diğerini ezmez.

Ücretsiz başlamanın 3 yolu

1) Ollama — anahtar yok, kayıt yok · 2) Gemini / OpenRouter / Groq — ücretsiz anahtar, kart istemez · 3) Kredi yüklü API'ler

🦙

Anahtarsız: Ollama

  1. ollama.com/download → Download for Windows → kur
  2. Komut isteminde: ollama pull qwen2.5:7b (zayıf PC: qwen2.5:3b)
  3. Panelde Ollama kartı → Test Et. Bitti.
Veri bilgisayarından çıkmaz, süresiz ücretsiz. 8 GB RAM'de 3B, 16 GB'de 7B model rahat çalışır.
✦

Ücretsiz anahtar: Gemini (2 dakika)

  1. aistudio.google.com/apikey
  2. Google hesabıyla giriş
  3. Create API key → proje seç → AIza... anahtarı kopyala
  4. Panelde Gemini kartı → anahtarı yapıştır → 💾 Kaydet → Test Et
Ücretsiz kota: ~dakikada 10, günde ~250 istek. Kart gerekmez.
⇄

Ücretsiz anahtar: OpenRouter (30+ model)

  1. openrouter.ai → Sign in (Google ile)
  2. Profil → Keys → Create Key → sk-or-v1-...
  3. Panelde OpenRouter kartı → yapıştır → Kaydet
  4. Ücretsiz model için model adının sonuna :free ekle, örn: deepseek/deepseek-chat-v3-0324:free
Ücretsiz: günde 50 istek. $10 kredi yüklersen 1000'e çıkar.
💳

Ücretli: OpenAI / Claude

OpenAI
  1. platform.openai.com → Sign up
  2. Settings → Billing → kredi ekle (min $5)
  3. API keys → Create secret key
Anthropic Claude
  1. console.anthropic.com → Sign up
  2. Plans & Billing → kredi (min $5)
  3. API Keys → Create Key

Anahtar güvenliği

  • Anahtar yalnızca tarayıcının kendi deposunda (chrome.storage.local) tutulur — hiçbir sunucuya gitmez, sadece seçtiğin sağlayıcıya gider.
  • Otomatik akış PKCE (S256) kullanır — istemci sırrı gerekmez, aracı sunucu yok.
  • Anahtarı kimseyle paylaşma; sızarsa sağlayıcı panelinden Revoke de.
  • Her sağlayıcıya harcama limiti koy (çoğunda Settings → Limits var).
  • Şüphelenirsen 🔒 Kilitle ile AI erişimini tamamen kes — anahtar dursa bile işlem yapılamaz.

Yapay zekâ ne yapabilir? İstediğin an kes.

Misyon nedir? (kalıcı hedef)Tek seferlik görev yerine büyük hedef verirsiniz; ajan kendi görev listesini kurar ve durmadan yürütür.
Örnek: "site-adresim.com'a git, hesabıma bağlan, blog seç, tema düzenle, reklam geliri üretecek şekilde yapılandır. Hedef: ayda 100$ gelir."
Nasıl: Görev sekmesi → 🎯 Misyon → hedefi yaz → 🚀 Misyonu başlat.
Misyon nasıl çalışır?1) Plancı hedefi 4-10 somut adıma böler (her adımın sayfada kontrol edilebilir bir ölçütü olur).
2) Yürütücü her adımı ajan olarak çalıştırır (ayrı pencere, hafıza, sağlayıcı devralma).
3) Doğrulayıcı sayfaya bakıp adımın gerçekten tamamlandığını kontrol eder; tamamlanmadıysa 3 kez tekrar dener.
4) Döngü alarmla sürer — tarayıcı kapansa bile panel açılınca devam eder.
Misyonu duraklat / adım atlaPanel → Misyon panosu → ⏸ Duraklat (kaldığı adım kaydedilir) · ▶ Sürdür · her adımın yanında atla · 🗑 misyonu siler.
Ajan tekrar tekrar sekme açıyorYeni sürümde koruma var: aynı adrese ikinci kez gitme isteği engellenir, adres ajanın hafızasına yazılır ve tekrar denenmez. Ayrıca görev kendi penceresinde çalışır.
Ajan mevcut sekmelerimde çalışıyorGörev sekmesinde 🗔 Yeni pencere seçili olsun (varsayılan). Böylece ayrı pencere açılır, sizin sekmeleriniz karışmaz. 📑 Mevcut sekme seçilirse açık sekmeyi kullanır.
Token/kota bitti, görev yarıda kaldıOtomatik devralma çalışır: sıradaki hazır sağlayıcıya geçip kaldığı adımdan devam eder. Sıra: xKiro → Gemini → Groq → OpenRouter → ModelScope → Ollama/LM Studio. Paneldeki 🧠 Görev hafızası kartında ▶ Kaldığı yerden devam et düğmesi vardır.
Ajan görevi hatırlıyor mu?Evet. Her adım diske yazılır: hedef, adım numarası, yapılan işlemler, öğrenilen URL/sayfa notları, tükenen sağlayıcılar. Tarayıcı kapansa, bilgisayar yeniden başlasa bile panel açılınca görev kartı görünür ve devam ettirilebilir.
